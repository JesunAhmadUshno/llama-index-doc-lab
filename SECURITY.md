# Security policy

Report a vulnerability privately through GitHub's "Report a
vulnerability" button on this repository's Security tab. Please do not
open a public issue for it. You will get a reply within 7 days.

Scope: the code in this repository. The study runs locally, makes no
network calls during scored runs and exposes no service. No credential
is stored in this repository; scripts/jev_claim_check.py calls a local
connector helper that keeps its credential outside the repo.
